# BMI-Calculator
# Python Mini Projects

A menu-based Python program that includes three small projects I made while learning Python.

## Projects

1. **BMI Calculator**: Takes your weight (kg) and height (m) and tells you if you are underweight, normal weight, overweight or obese.
2. **Zodiac Calculator**: Takes your birth year and tells you your Chinese zodiac animal.
3. **Birthday Finder**: Shows 5 number sets. You tell which sets contain your birthday day and the program finds it.

## How to Run

1. Install Python 3,Pycharm etc.
2. Download Python-Lab5-ConditionalStatements.py from this repository.
3. Run it in the terminal:

   python Python-Lab5-ConditionalStatements.py

4. Choose a project from the menu by typing its number (0 to exit).
